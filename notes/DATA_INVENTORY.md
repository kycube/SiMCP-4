# The game's data (inventory, 2026-10-08)

Made with `re/dbpf_inventory.py OUT` (reader: `sc4_mcp/dbpf.py`) over every DBPF file in the GOG install except the
shipped regions. Counts and structure only; the dumps themselves (exemplars, texts, Lua, UI scripts) stay in the
local workbench. "VERIFY" marks community names not yet confirmed from the game's own code or data.

## Containers

All 23 files are DBPF 1.0 with index 7.0 (20-byte entries) and a DIR record listing the compressed records.
Compressed records are `u32 total length` + a QFS (EA RefPack) stream - the same RefPack as SimCity 3000's
Building Architect (`10 FB` + 3-byte big-endian size). The inventory decoded every exemplar, cohort, LTEXT, Lua
and UI/INI record plus the first 50 records of every other type, with no failures apart from the audio records
that share the LTEXT type id. `SimCity 4.cfg` (user preferences) is a DBPF too (2 records).

## User Plugins (pinned set, see PHASE0.md)

786 files, 945 MB: 755 `.dat`, 6 `.SC4Model`, 12 DLLs (+ their logs and 2 INIs). `re/dbpf_inventory.py OUT
--plugins <Plugins>` (2026-10-08): 761 DBPF files, all readable; 67,803 exemplars (1,124 of them text `EQZT`) +
632 cohorts, 13,598 LTEXT, 41 Lua scripts, 34 RUL files (NAM's network rules, 62 MB), 236,764 FSH textures,
99,730 S3D models, 73,588 SC4Path, 2,927 effect directories, plus types the game's own data does not use: XML
(0x88777601/2, 328), JPEG (0x74807101/2, 302) and BMP (0x66778001/2, 284) - VERIFY their purpose (probably
NAM / CAM documentation and previews). Exemplar types: 48,546 network pieces (0x0B), 13,059 type 0x21, 2,050 rail
(0x0A), 1,781 props, 1,013 bridge pieces (0x06), 747 lot configurations, 271 buildings (0x02), 139 zone catalogue
entries (0x28). As in `Sound.dat`, 0x2026960B also carries WAV audio (`RIFF`) - 108 such records in CAM - besides
LTEXT; a reader must check the 0x1000 marker.

## What this gives the project

- **Text**: every string the UI shows, per language (LTEXT) - names, advisor messages, news, dialogs.
- **UI layouts**: window and control ids of every dialog (the GZWin* game commands address windows by these ids).
- **Lua**: the advisor, tutorial and U-Drive-It mission scripts the game runs.
- **Exemplars**: the catalogue of everything placeable (lots, buildings, props, flora, networks), ordinances,
  disasters, tuning and simulator parameters - the base for `tool_catalog`/`place_*` and for new content.
- **Content formats** needed to make new buildings / lots / props: exemplar + cohort, LotConfig properties, S3D,
  FSH, PNG icons, LTEXT names, all inside a DBPF written by `sc4_mcp/dbpf.py` (round-trip tested).
